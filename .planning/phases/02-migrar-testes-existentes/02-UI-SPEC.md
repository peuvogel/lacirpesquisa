# Phase 2 — UI Design Contract

> Visual and interaction contract for migrating t de Student, Correlação Pearson/Spearman, and Prais-Winsten into the shared FlowSteps shell, with deep chart customization on migrated tests. Generated by gsd-ui-researcher, verified by gsd-ui-checker.
>
> **Inheritance rule:** Phase 2 adds **surfaces and copy** only. All spacing, typography, color tokens, shell chrome, and global interaction patterns come from `01-UI-SPEC.md` + `src/app/theme.css`. Do not introduce Inter, Roboto, purple, or new accent colors.
>
> **Note on process:** This session ran without interactive user confirmation (AskUserQuestion unavailable). Every decision in `02-CONTEXT.md` and locked items in the user prompt are treated as **locked**. Remaining choices are Claude's Discretion, flagged below.

## Spacing Scale

**Inherited unchanged from Phase 1** (`01-UI-SPEC.md` § Spacing Scale + `theme.css` radius tokens):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, inline badge padding |
| sm | 8px | Compact form spacing, choice-card internal gaps |
| md | 16px | Default element spacing, card padding, customizer control stacks |
| lg | 24px | Section padding, Configurar panel gutters, customizer panel padding |
| xl | 32px | Gap between metric grid and chart block, choice-card grid gap |
| 2xl | 48px | Major breaks above didactic-cards accordion |
| 3xl | 64px | Unused in Phase 2 inner panels (reserved for page-level placeholders) |

**Radius:** `--radius-sm: 8px`, `--radius-md: 12px`, `--radius-lg: 16px` — choice cards, customizer panel, didactic cards use `--radius-md`; chart container uses `--radius-lg`.

**Phase 2 exceptions:**
- **Choice cards** (`ModeChoiceCard`, `MethodChoiceCard`): minimum **44px** tap height on the card body (title + one-line description), even when content is short — WCAG 2.5.5.
- **ChartCustomizer** icon-only reset control: **44×44px** hit area.
- **Didactic card** collapse trigger: full card header row is the hit target (min 44px height).

## Typography

**Inherited unchanged from Phase 1** — exactly 4 UI sizes, 2 weights:

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 16px | 400 | 1.6 |
| Label | 14px | 700 | 1.4 |
| Heading | 20px | 700 | 1.2 |
| Display | 32px | 700 | 1.15 |

**Data/mono register:** IBM Plex Mono, 14px, 400, line-height 1.55 — series preview tables, pasted example snippets inside didactic cards, axis title inputs in `ChartCustomizer`.

**Phase 2 mapping:**
- Configurar section titles (`"Tipo de comparação"`, `"Método de correlação"`, `"Personalizar gráfico"`): **Heading (20px/700)**.
- Choice card titles (`"t independente (Welch)"`, `"Pearson"`): **Label (14px/700)**; card descriptions: **Body (16px/400)** at `text-muted-foreground`.
- Metric values in `ResultsPanel`: **Heading (20px/700)** — same as Phase 1 demo.
- Soft-reset notice body: **Body (16px/400)**.
- Customizer group labels (`"Tipo de gráfico"`, `"Eixos"`, `"Anotações"`): **Label (14px/700)**.
- Demo sidebar subtitle unchanged; add inline **Label** badge `"Demonstração"` next to demo title in sidebar + modal only.

## Empty / Error / Loading States

**Empty:** Inherited Dados empty state (Phase 1). Configurar without loaded input: inherited fallback copy. Prais series preview with 0 valid rows: **"Nenhum ponto temporal válido encontrado. Volte a Dados e confira as colunas de tempo e valor."**

**Error:** Parse errors — inherited Phase 1 Alert. Engine errors — Copywriting Contract table (Portuguese, inline Alert destructive border). Mapas handoff with wrong shape: fall through to column preview validation errors.

**Loading:** Chart skeleton (Phase 1) while Chart.js mounts. Customizer changes: no full-page loader — chart updates in place; if recompute >100ms, show subtle opacity **0.6** on chart container until `ChartCanvas` `onCanvasReady` fires again.

## Accessibility

**Inherited Phase 1 requirements** (contrast, focus rings, modal trap, `aria-live` on parse errors, reduced motion on route entry) apply unchanged.

**Phase 2 additions:**
- **Choice cards:** container `role="radiogroup"` with `aria-label` matching section heading; each card `role="radio"` + `aria-checked`; arrow keys move selection within group (roving tabindex).
- **DidacticCards:** `CollapsibleTrigger` includes `aria-expanded`; card title in trigger text.
- **ChartCustomizer:** every switch/checkbox has visible `<Label>`; chart-type chips are `role="radio"` in `radiogroup` **"Tipo de gráfico"**.
- **Prais chart tabs:** shadcn `Tabs` with `aria-selected` on **"Tendência"** / **"Resíduos"**; customizer applies to active tab's chart (helper text: **"As opções abaixo afetam o gráfico selecionado."**).
- **SoftResetAlert:** `role="status"` + `aria-live="polite"` so screen readers announce mode changes.
- **Customizer color themes:** never the sole signal — active theme also shows text label on selected option.

## Claude's Discretion (flagged decisions)

1. **α change re-runs analysis in place on Resultados** — CONTEXT silent; chosen to avoid punishing users tweaking significance level after seeing results. Override: require return to Configurar if product owner prefers stricter flow.
2. **ChartCustomizer 3 theme presets only** — D-04 allows themes beyond brand; capped at three named presets to avoid hex-picker scope creep.
3. **Customizer collapsible below `lg`** — mobile layout choice; desktop side panel matches "professional tool" expectation from user brief.
4. **Didactic cards allow multiple expanded** — pedagogical; users may compare cards. Alternative: accordion single-open.
5. **Prais-Winsten chart tabs** — RESEARCH left layout open; tabs keep one canvas + one customizer target (simpler PNG export) vs stacked dual charts.
6. **"Usar exemplo" casing** — canonical **"Usar exemplo"** per D-03 (demo currently uses lowercase `"usar dados de exemplo"` — align migrated tests + fix demo in execution wave).
7. **Soft-reset auto-navigate to Configurar** when switch happens on Resultados — ensures user cannot view stale results; not explicitly in CONTEXT but required by D-13 intent.
