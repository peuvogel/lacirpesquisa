## As duas exceções estruturais (verificadas na pesquisa)

1. **Soft reset (Poisson, caso 'shows soft reset alert when column role is adjusted after confirm', linha 146):** hoje ele clica 'Configurar' uma segunda vez, depois de já estar em Resultados, para reabrir a configuração. No layout scroll a seção 'Dados e configuração' **nunca desmonta** (`showConfig` fica verdadeiro para sempre depois que o dado carrega), então esse segundo clique simplesmente some — o `<select>` de papel da coluna já está na tela e o `user.selectOptions(screen.getByLabelText(/Papel da coluna contagem/i), 'ignorar')` funciona direto.
2. **'keeps Resultados locked until a dataset is confirmed' (TesteDemo, linha 60):** hoje lê um botão 'Resultados' desabilitado. No layout scroll não existe botão desabilitado — a seção Resultados **não é montada**. A asserção equivalente é `expect(screen.queryByRole('region', { name: 'Resultados' })).not.toBeInTheDocument()`. Este caso **não** chama o helper.
