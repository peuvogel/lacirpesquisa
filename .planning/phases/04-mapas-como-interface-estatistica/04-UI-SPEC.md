# Phase 4 — UI Design Contract

> Visual and interaction contract for **Mapas como interface estatística** — the didactic single-screen map workspace where capacitação trainees select territories, form named analysis groups, configure time and diseases/variables per group, review a suggested test, and hand off tabular data to Estatística.
>
> Generated by gsd-ui-researcher (`--auto`, no user prompts). All decisions in `04-CONTEXT.md` are **locked**. Brand tokens inherit from `01-UI-SPEC.md` and the live `src/app/theme.css` (theme.css wins on hex values where they differ). Everything else below is Claude's Discretion, resolved here as the lowest-risk didactic default.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | shadcn (`components.json` present — initialized) |
| Preset | `vite`, style **radix-nova**, base color **neutral**, CSS variables **on**, radius **0.75rem**, icon library **lucide** — per `components.json` |
| Component library | Radix primitives via shadcn: `button`, `dialog`, `sheet`, `badge`, `tabs`, `checkbox`, `tooltip`, `alert`, `select`, `label`, `switch`, `collapsible` |
| Icon library | `lucide-react` |
| Font | **Sora** (UI sans — headings, nav, labels, buttons, body) + **IBM Plex Mono** (data — paste preview, territory match tables, numeric summaries) — unchanged from Phase 1 |

**Brand continuity:** Do not introduce purple, violet, or generic AI-gradient aesthetics. Map choropleths use **sequential teal/neutral scales** derived from `--color-accent` and muted surface tones — never a rainbow or purple heat scale.

**Phase 4 additions:** No new third-party registries. Drag-and-drop may use HTML5 DnD or a lightweight library — visual contract below is library-agnostic.

## Spacing Scale

Inherited from Phase 1 — multiples of 4 only:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps, badge internal padding, group chip internal padding |
| sm | 8px | Compact list spacing, preset pill gaps, legend item gaps |
| md | 16px | Default element spacing, panel internal padding, group bar padding |
| lg | 24px | Section padding, page horizontal gutters, review dialog body padding |
| xl | 32px | Gap between map canvas and side panel, group bar ↔ map spacing |
| 2xl | 48px | Major breaks above choropleth legend block |
| 3xl | 64px | Page top spacing below global header |

**Radius scale:** `--radius-sm: 8px` (chips, inputs, preset pills), `--radius-md: 12px` (buttons, small cards), `--radius-lg: 16px` (panels, drawers, review dialog) — per `theme.css`.

**Exceptions:**
- Icon-only map controls (zoom back to Brazil, clear selection, paste toggle) use **44×44px** minimum hit targets.
- SVG geographic paths do not follow the spacing scale; hover/focus/selection stroke-width stays **2px** (`vector-effect: non-scaling-stroke`).
- Group drop zones in the top bar use **min-height 48px** (touch-friendly drop target) even though internal chip height is ~32px.

## Color

Canonical values from `src/app/theme.css` (single source of truth):

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#09090b` (`--color-bg`) | Page background, map canvas backdrop |
| Secondary (30%) | `#0f0f12` (`--color-surface`), `#18181b` (`--color-elevated`) | Group bar, side panel, drawer, review dialog, choropleth legend card, preset pills |
| Accent (10%) | `#209978` (`--color-accent`) | **Reserved for:** primary CTAs, selected UF fill+stroke, group membership glow, active group chip border, focus rings, choropleth highlight band, "disponível" badges, drop-zone drag-over border, active temporalidade tab, suggested-test highlight row |
| Accent soft | `rgba(32, 153, 120, 0.12)` (`--color-accent-soft`) | Hover UF fill, group chip background, intersection variable row tint |
| Accent border | `rgba(23, 121, 94, 0.45)` (`--color-accent-border`) | Selected UF stroke, group chip outline, drop zone idle dashed border |
| Destructive | `#ef4444` | Unmatched territory labels, partial-variable "não existe em…", destructive clear-group confirm |
| Warning | `#f59e0b` | Large paste file hint, incomplete group config nudge ("falta escolher o período") |

**Choropleth data scale (sequential, didactic):** 5 steps from `#18181b` (no/low data) → `#1a3d34` → `#209978` → `#2eb896` → `#5eead4` (highest). Legend shows labeled breaks in plain PT ("Baixo" … "Alto"). Never use purple, magenta, or red-green diverging scales unless comparing two periods (then teal vs muted amber, both labeled).

**Accent reserved for:** primary CTAs, selected/eligible territory glow, active group indicators, focus rings, choropleth emphasis, drag-over drop zones, suggested-test highlight. **Never** apply teal to body text, disabled controls, or decorative-only surfaces.

**Contrast:** `#209978` on `#09090b` ≈ 6.8:1 (AA pass). Body text `#f4f4f5` on dominant ≈ 15:1. Muted text `#a1a1aa` on dominant ≈ 5.8:1 — do not go lighter for informational text.

## Layout Regions

Single-screen **Mapas workspace** (MAP-10, D-01). No rigid stepper. Regions stack as follows on desktop (≥1024px):

```
┌─────────────────────────────────────────────────────────────┐
│ AppHeader (global, unchanged)                                │
├─────────────────────────────────────────────────────────────┤
│ Page title: "Mapas" (Display)                                │
├─────────────────────────────────────────────────────────────┤
│ R1 — GroupBar (full width, sticky below title on scroll)     │
│   [Preset pills] [Grupo 1 ▾] [Grupo 2] [+ Criar grupo]      │
├─────────────────────────────────────────────────────────────┤
│ R2 — SelectionSummaryStrip (full width, always visible)      │
│   Território · Grupos · Tempo · Agravos (plain PT chips)   │
├──────────────────────────────┬──────────────────────────────┤
│ R3 — MapCanvas (~58%)        │ R4 — ContextPanel (~42%)     │
│   Brazil / UF drill map      │   Mode A: explore hint       │
│   + choropleth legend        │   Mode B: group config       │
│   + breadcrumb drill nav     │   (time → variables)         │
│   + paste/match affordance   │   Mode C: paste report       │
├──────────────────────────────┴──────────────────────────────┤
│ R5 — PrimaryActionBar (bottom of ContextPanel or sticky)     │
│   [Revisar e analisar]  secondary: [Colar dados] [Limpar]   │
└─────────────────────────────────────────────────────────────┘
```

| Region | Purpose | Visibility |
|--------|---------|------------|
| **R1 GroupBar** | Drop targets for drag-created groups; preset one-click group creation (Norte, Nordeste, CO, Sudeste, Sul); macrorregião de saúde chips; renamable group tabs | Always visible once page loads |
| **R2 SelectionSummaryStrip** | Plain-PT sentence + chips: `{territórios}` × `{N grupos}` × `{período}` × `{agravos}` — updates live (D-02) | Always visible; shows placeholder copy when empty |
| **R3 MapCanvas** | Geographic interaction plane: UF multi-select, glow, choropleth, drill-down ladder (UF → município / mesorregião / macrorregião de saúde), breadcrumb back navigation | Always visible; focal point (~58% width desktop) |
| **R4 ContextPanel** | Progressive disclosure (D-03): empty/explore → per-group config drawer content inline on desktop → paste match report | Always occupies right column; content mode switches |
| **R5 PrimaryActionBar** | **"Revisar e analisar"** opens review dialog when ≥1 group has territory + time + ≥1 variable | CTA disabled until minimum valid shape |

**Review dialog (R6):** shadcn `Dialog`, full-width max `640px`, replaces Phase 1 `IniciarPesquisaModal` stub. Not a separate route — overlay on the same screen (D-20–D-22).

**Tablet (768–1023px):** R3 map **100% width** on top; R1/R2 unchanged; R4 becomes **Sheet** drawer triggered by active group chip or "Configurar grupo" button; R5 sticky bottom bar above safe area.

**Below 768px:** Out of primary scope (D-deferred touch-first). Minimum: map scrollable, Sheet for panel, GroupBar horizontally scrollable — no redesign required this phase.

## Key Screens

### 1. Mapas — Initial / Explore (D-03 step: map first)
**Focal point:** R3 MapCanvas with Brazil UF choropleth or neutral fill. R2 shows empty summary copy. R4 Mode A empty state. R1 shows one empty drop zone "Grupo 1". GroupBar presets visible but not required.

### 2. Mapas — Territories selected, ungrouped
**Focal point:** Selected UFs glow teal on map (D-04). R2 updates territory chips. R5 **Criar grupo com seleção** enabled. Drag ghost available from selected paths to R1.

### 3. Mapas — Group forming (drag or button)
**Focal point:** R1 drop zone drag-over highlight. On drop or button: group chip populated, map paths show group membership (stronger glow + group index badge). R4 opens GroupConfigPanel for that group.

### 4. Mapas — Group config: temporalidade (D-09/D-10)
**Focal point:** R4 GroupConfigPanel top section — **Quando analisar?** Year select(s) or range inputs. Compare mode shows A vs B when toggled. R2 summary updates tempo segment.

### 5. Mapas — Group config: variables (D-11)
**Focal point:** Variable checklist below time controls. Intersection rows teal-tinted; partial rows with destructive trailing note. Provenance badge per variable. R2 summary updates agravos segment.

### 6. Mapas — Multi-group active
**Focal point:** R1 shows multiple GroupChips; clicking chip switches R4 context and map highlight set. R2 shows aggregate summary across groups. Preset click creates/fills a new group in one action (D-07/D-08).

### 7. Mapas — UF drill-down (MAP-03)
**Focal point:** MapBreadcrumb + município/mesorregião/macrorregião choropleth in R3. Selection and grouping rules extend to sub-UF geographies. Back navigation returns to Brazil view without losing groups.

### 8. Mapas — Territory paste (MAP-02/MAP-04)
**Focal point:** R4 Mode C — paste textarea + matched/unmatched report. Matched territories highlight on map; unmatched listed in destructive-adjacent Alert with retry guidance.

### 9. ReviewHandoffDialog (D-20–D-22)
**Focal point:** **Sua seleção** recap + **Teste sugerido** card + **Usar outro teste** select + **Ir para Estatística**. Secondary collapsed **Ver fontes oficiais** links.

## Empty / Error / Loading States

**Empty**
- No interaction yet — see Copywriting (ContextPanel Mode A + R2 placeholder + MapLegendHint)
- Group exists but no time — **Quando analisar?** block
- Time set but no variables — **O que comparar?** block
- No choropleth variable chosen — map shows neutral geography fill; legend hidden with hint "Escolha uma variável para colorir o mapa"

**Error**
- Territory paste unmatched — inline Alert + unmatched list; map still usable
- Partial variable — non-blocking inline destructive note (not Alert)
- Group incomplete at review — inline Alert above disabled CTA
- Geo bundle load failure — Alert in map region + retry/back link
- Handoff with unavailable suggested test — fall back to test picker default; never silent failure

**Loading**
- UF drill-down geo lazy-load — map area skeleton (fixed aspect ratio) + "Carregando mapa…" 14px muted
- Paste parse — brief inline spinner in paste panel
- Review handoff assemble — primary button loading state **Ir para Estatística** (~instant but required for a11y)
- Choropleth recalc — cross-fade map fills 200ms; no full-page spinner

## Motion

Subtle, brand-teal, didactic — no purple glow spam (CONTEXT discretion).

| Animation | Duration | Easing | Reduced motion |
|-----------|----------|--------|----------------|
| Page mount (`.lacir-route-enter`) | 220ms | ease-out | disabled — instant show |
| UF select glow (`.lacir-map-glow`) | 300ms | ease-in-out | static glow, no pulse |
| Drop zone highlight | 150ms | ease-out | instant border change |
| Group chip add | 200ms | ease-out | fade only, no slide |
| Choropleth fill update | 200ms | ease | instant swap |
| Sheet drawer open (tablet) | Radix default | — | Radix reduced-motion respected |
| Review dialog open | Radix default | — | — |

**`.lacir-map-glow` definition:** `filter: drop-shadow(0 0 6px rgba(32, 153, 120, 0.55)) drop-shadow(0 0 12px rgba(32, 153, 120, 0.25))` on selected paths; optional 2s pulse on **eligible** (selected, not yet in group) only when `prefers-reduced-motion: no-preference`. Pulse amplitude ≤ 15% opacity change.

**No** parallax, bounce, or chart-editor-style glow (unlike Estatística chart edit mode). Map motion stays calmer than Results panel.

## Accessibility

- **Contrast:** pre-checked pairs in Color section; choropleth legend labels must meet AA on `#18181b` legend card background.
- **Focus visibility:** all interactive elements — map paths, group chips, preset pills, drop zones, temporalidade controls, review dialog controls — use `focus-visible: 2px solid var(--color-accent)` with offset.
- **Keyboard map access:** every selectable geo path: `tabIndex={0}`, `role="button"`, `aria-label="{Nome completo}"`, `aria-pressed` for selection. Enter/Space toggles. Escape clears **current selection** (ungrouped); Shift+Escape opens clear-all confirm if groups exist.
- **Keyboard group creation:** **Criar grupo com seleção** must work without drag (D-05). Group rename: F2 on focused chip.
- **Drag alternatives:** all drag outcomes reachable via button/context menu (D-05).
- **Color + text:** group membership shown by glow **and** group number badge on path; choropleth always paired with legend labels; unavailable tests show text badge not color alone.
- **`aria-live`:** SelectionSummaryStrip `polite`; paste match report `polite`; review suggestion update `polite`.
- **Dialog focus trap:** ReviewHandoffDialog — Radix default; restore focus to **Revisar e analisar** on close.
- **Drop zones:** `aria-dropeffect="move"` during drag; `aria-label="Grupo {n}, solte estados selecionados aqui"`.
- **Reduced motion:** all first-party map animations guarded under `prefers-reduced-motion: reduce`.
