    1. Declare `--font-sans` as `'Sora', ui-sans-serif, system-ui, sans-serif` and `--font-mono` as `'IBM Plex Mono', ui-monospace, SFMono-Regular, monospace`.     2.     4. In `src/index.css`, add `@import "./app/theme.css";` immediately after `@import "tailwindcss";`, then remap the shadcn CSS variables onto LACIR tokens inside the existing `:root`/dark block: `--background` → bg, `--card`/`--popover` → surface/elevated, `--primary` → accent with `--primary-foreground` `#04120c`, `--destructive` → destructive, `--border`/`--input` → border, `--ring` → accent, `--muted-foreground` → text-muted, `--foreground` → text. This is what makes an unmodified shadcn `Button` render teal instead of neutral, so no later plan needs per-component color overrides.

    5. Remove the temporary body background/color rule 01-01 put in `src/index.css` and replace it with a `@layer base` rule setting `body` to bg/text tokens, `font-family: var(--font-sans)`, `font-size: var(--text-body)`, and `color-scheme: dark`.

    6. Add a `@layer base` `:focus-visible` rule giving every focusable element a `2px solid var(--color-accent)` outline with `2px` offset (01-UI-SPEC.md § Accessibility requires a visible teal focus ring app-wide; doing it once here means no component can silently ship without one).

    Use no purple values, no `#22c55e`, and no `--green*` token names — the legacy green/purple lineage stops here (D-16).
