## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| third-party SVG asset → bundle | Externally sourced geometry is committed into the app and rendered into the DOM |
| map/panel selection → session | User selection crosses into shared session state read by other routes |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-SVG | Tampering | Externally sourced Brazil SVG | mitigate | Geometry is sanitized at import (scripts, `on*` handlers, `foreignObject`, external `href` stripped), committed as plain data rather than a raw markup string, and rendered as React elements — never via `dangerouslySetInnerHTML`; a test asserts the geometry module contains no script/handler/href strings |
| T-01-SC4 | Tampering | Geo dependency creep | mitigate | No new package is installed; the acceptance criteria assert `chartjs-chart-geo`, `topojson-client`, and `d3-geo` are absent from `package.json` (01-RESEARCH.md Pattern 6) |
| T-01-NET | Information Disclosure | Runtime call to IBGE or any map API | mitigate | The IBGE fetch happens once at development time and its output is committed; the shipped app makes no network request for map data, preserving the offline-classroom posture |
| T-01-MOCK | Repudiation | Mock data mistaken for real availability | accept | The fixture file states in a top comment that it is Phase 1 mock data, and `Iniciar pesquisa` is an explicit stub this phase; the didactic risk is acknowledged and closed in Phase 4 |
</threat_model>
