<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| app → external TABNET origin | The Portal DATASUS link navigates the user to a third-party government site in a new tab |
| registry data → navigation | Registry ids select which module component mounts |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-TAB | Spoofing | `PortalDatasusLink` opening a new tab | mitigate | `rel="noopener noreferrer"` blocks `window.opener` access and referrer leakage; enforced by this plan's grep gate on the component file |
| T-01-NAV | Elevation of Privilege | Selecting an unbuilt module id | mitigate | Both surfaces gate on `isTestAvailable(id)` and unavailable rows are non-interactive elements rather than click-handled buttons, so there is no code path that mounts a nonexistent module |
| T-01-XSS3 | Tampering | Sidebar and modal copy | mitigate | Every string is a static literal from the registry rendered as a JSX text child; no user input reaches these surfaces and no HTML is constructed |
| T-01-DRIFT | Repudiation | Sidebar/modal disagreeing about availability | mitigate | One `TEST_REGISTRY` with a test asserting exactly one available entry; both renderers import it, and the shared row component makes divergence require deleting a shared import |
</threat_model>
