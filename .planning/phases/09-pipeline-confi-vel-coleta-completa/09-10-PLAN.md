<interfaces>
`upload.py`:

- `connect() -> psycopg.Connection` — lê `SIH_PIPELINE_DB_URL` de `.env.pipeline`; valida que o host
  contém `pooler.supabase.com` e a porta é `5432`, levantando `RuntimeError` caso contrário
- `copy_to_staging(conn, tabela, linhas) -> int` — `cur.copy("COPY <tabela>_staging (...) FROM STDIN")`,
  devolve a contagem escrita
- `swap(conn, tabela) -> None` — uma transação: `truncate` da tabela viva, `insert ... select` do
  staging (ou `alter table ... rename`, o que o executor medir como mais rápido), `drop` do staging
- `recount_via_postgrest(tabela, filtros) -> int` — leitura paginada via `Range`/`content-range`,
  seguindo até o fim; levanta se `content-range` indicar total maior do que foi lido
- `release_cache(nomes_de_arquivo) -> None` — só é chamada quando a contagem confere
- `TOMBSTONES` — carregado de `scripts/catalog/rename-map.json` via `repo_root()`; nenhum
  `disease_id` tombstone pode entrar no `COPY`
</interfaces>

## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Pipeline local → banco de produção | A credencial privilegiada escreve direto na tabela que o app serve |

| PostgREST → auditoria do operador | Uma leitura truncada convenceria o operador de que a coleta está certa |
