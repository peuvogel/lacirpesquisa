`codigos.py` — canonização compartilhada, consumida também por `population.py` (09-06):

- `sexo_sih(valor) -> str | None` — `SEXO` do SIH (`{1, 3}`, medido ao vivo) para `"M"`/`"F"`

- `load_cid_map() -> dict[str, str]` — lê `scripts/catalog/lista-morb-cid.json` (chaveado por `tabnetCode`)
- `apply_corrections(cid_map, corrections) -> dict[str, str]` (reexportado de `corrections.py`)
- `build_index(cid_map) -> object` — estrutura de busca pré-compilada; o matcher do spike varre o mapa
  inteiro por registro, o que serve para 44 mil linhas e não para dezenas de milhões
- `match_category(diag_princ: str, index) -> str | None` — devolve o `tabnetCode`

`corrections.py`:
- `CORRECTIONS_PATH` — `scripts/catalog/cid-corrections.json`
- `load_corrections() -> list[dict]` — cada entrada tem `tabnetCode`, `oldRange`, `newRange`, `reason`,
  `reconciliationPair`
- `apply_corrections(cid_map, corrections) -> dict[str, str]` — substitui a faixa do `tabnetCode`,
  levantando `ValueError` se o `oldRange` da correção não bater com o valor atual do mapa (uma correção
  que descreve errado o estado de origem é bug, não correção)

`aggregate.py`:
- `NEEDED_COLUMNS = ["DIAG_PRINC", "MUNIC_MOV", "MUNIC_RES", "MORTE", "VAL_TOT", "DIAS_PERM", "ANO_CMPT"]`
- `aggregate_parquet_dir(path, index) -> list[Row]`
- `Row` carrega `(disease_id, grao, local, territorio_codigo, ano, internacoes, obitos, valor_total,
  dias_permanencia, taxa_mortalidade)`; `taxa_mortalidade = obitos / internacoes` quando
  `internacoes > 0`, e `None` (nunca `0`) quando `internacoes == 0`
